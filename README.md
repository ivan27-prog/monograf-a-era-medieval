# ⚔️ Monografía: Caballeros de la Inglaterra Medieval

Página web sencilla sobre los caballeros, órdenes y castillos de la Inglaterra medieval.

---

## 🛠️ Tecnologías
* HTML5
* CSS3 (`position`, `display` y colores personalizados)
* Bootstrap 5 / MDBootstrap (vía CDN)
* Font Awesome

---

## 🎨 Colores usados
* **Negro:** Fondo principal
* **Dorado:** Bordes y títulos
* **Rojo:** Botones y detalles
* **Blanco:** Texto

---

## 🧩 Componentes de Bootstrap usados
1. **Navbar (Breadcrumbs):** Barra fija arriba.
2. **Jumbotron (Header):** Portada de bienvenida.
3. **Cards (Grid):** 3 tarjetas para las órdenes y armas.
4. **Carousel:** Galería de imágenes de castillos.
5. **Footer:** Pie de página con créditos.

---

## 📁 Archivos
* `assets/`: Imágenes en formato `.png`.
* `index.html`: Estructura del sitio.
* `styles.css`: Estilos y personalización.

---

## 🚀 ¿Cómo verlo?
Solo abre el archivo `index.html` en tu navegador.
